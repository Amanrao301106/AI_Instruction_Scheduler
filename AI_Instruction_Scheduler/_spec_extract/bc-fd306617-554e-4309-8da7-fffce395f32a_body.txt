7. CPU PIPELINE MODEL
============================================================
Simulate a classic 5-stage pipeline:
IF -> ID -> EX -> MEM -> WB
Meaning:
IF  = Instruction Fetch
ID  = Instruction Decode
EX  = Execute
MEM = Memory Access
WB  = Write Back
The simulator must execute instructions cycle-by-cycle.
It must show exactly which stage each instruction occupies during
each cycle.
Example:
      C1 C2 C3 C4 C5 C6 C7I1 LOAD   IF ID EX MEM WB
I2 ADD       IF ID EX MEM WB
Dependency stalls must be calculated from the actual simulation.
Never hard-code stalls.
